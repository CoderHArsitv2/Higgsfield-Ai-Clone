## API key encryption — answering your question

Yes, and it's done properly. I read the code rather than assuming:

- **AES-256-GCM** with a fresh random nonce per encrypt ([cryptox.go](backend/pkg/cryptox/cryptox.go)). GCM is authenticated, so tampered ciphertext fails to open rather than decrypting to garbage.
